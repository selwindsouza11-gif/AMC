# Daily 10 — Math Challenge

A responsive daily set of 10 original AMC/AIME-style math problems, with hints, answer checking, and saved progress.

## Run locally

Open `index.html` in a browser. The site has no build step or external dependencies.

## Publish with GitHub Pages

The workflow in `.github/workflows/pages.yml` deploys the site when changes are pushed to `main`.

1. In the repository's **Settings → Pages**, set the source to **GitHub Actions**.
2. Push a commit to `main`, or run the **Deploy to GitHub Pages** workflow manually from the Actions tab.

Once deployed, the site will be available at <https://selwindsouza11-gif.github.io/AMC/>.
